# Introduction and Course Overview

Five-Star Battery Data is a self-paced course about turning battery datasets into open, structured, and machine-actionable research assets.

## What you will learn

- Why treating battery data as a reusable asset matters
- How the five-star ladder moves from access to linked data
- How the course is organized across notebooks, self-checks, and capstone material

## The Five-Star Battery Data framework

1. Publish your data on the web with a permissive license
2. Use structured data such as tables and JSON
3. Use open formats such as CSV, JSON, Parquet, and HDF5
4. Describe your data with ontologies
5. Link your data to other relevant resources

## How to use this course

- Start with the introduction video
- Work through stars 1 to 5 in order
- Use the capstone module to review applications, discussion, summary, and the course quiz

## Next step

Continue to the `star-1` module to publish a dataset on the web with an explicit license.

# Star 3 Lecture Notes

## What three-star battery data means

Star 3 is about packaging structured battery data in open, non-proprietary formats that are easy to parse across software tools and long-lived workflows.

## Why this matters

- Open formats reduce dependency on vendor-specific software.
- The same dataset can be optimized for different use cases such as tabular exchange, metadata transport, or efficient storage.
- Open formats make it easier to connect research data to broader digital infrastructure.

## What to focus on in this lesson

- Compare the tradeoffs between CSV, JSON, HDF5, Parquet, and plain text.
- Understand when a format is human-friendly versus machine-efficient.
- Think about portability, interoperability, and preservation.
